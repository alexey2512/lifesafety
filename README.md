# ПОД РУКОЙ

Образовательный гид для студентов: аптечки для дома, автомобиля, путешествия, похода и рабочего места.

**Сайт:** https://alexey2512.github.io/lifesafety/

Пять интерактивных списков с локальным сохранением, сравнение комплектов, хранение и проверяемые источники. HTML/CSS/JavaScript, без сборки и сервера. Откройте index.html или включите GitHub Pages из ветки main, папка /.

Личные наборы — образовательные ориентиры, не назначения лечения. Автомобильная и рабочая аптечки — по приказам Минздрава России 260н и 262н от 24.05.2024. Дата сверки: 21.11.2026.

Шрифт Manrope распространяется по SIL OFL; текст лицензии в assets/OFL-Manrope.txt.
